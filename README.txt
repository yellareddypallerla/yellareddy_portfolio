Before publishing:
1. Confirm your LinkedIn and GitHub profile links in index.html are correct.
2. Review all technical/project descriptions and remove anything confidential or inaccurate.
3. Publish using GitHub Pages:
   - Create/sign in to GitHub.
   - Create a repository named: yourusername.github.io
   - Upload index.html to the repository root.
   - In repository Settings > Pages, select deploy from branch (main / root), if needed.
   - Your public website will appear at https://yourusername.github.io after GitHub finishes publishing.
